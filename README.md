# אתר – לינור נזרי-שר, קלינאית תקשורת

האתר החי: https://nisanman.github.io/linor-speech/

## התמונה הכללית – איך האתר עובד
```
אתה עורך טקסט          →   build.py בונה    →   האתר המוכן     →   גיטהאב מפרסם
(content.json, pages/)      את האתר             (תיקייה dist/)       (בכל push)
```
כמעט אף פעם לא כותבים HTML – עורכים טקסט, והסקריפט הופך אותו לאתר.

## 📄 `content.json` – הפרטים הכלליים
הקובץ שעורכים הכי הרבה. בנוי מחלקים:

| חלק | מה יש בו |
|---|---|
| `site` | הכותרת בגוגל ובלשונית (`title`), התיאור לגוגל (`description`), כתובת האתר (`url`), תמונת השיתוף לוואטסאפ (`image`) |
| `google` | מזהה Google Analytics (`analytics_id`, מתחיל ב־`G-`) והקוד של Search Console (`site_verification`). ריקים = כבויים |
| `brand` | השם, המקצוע, והשורה הקטנה מעל השם בדף הבית (`eyebrow`) |
| `photo` / `photo_shape` | התמונה בדף הבית, וצורתה – `circle` (עיגול) או `square` (ריבוע) |
| `home_buttons` | הכפתורים בדף הבית: טקסט, `link` (`whatsapp` / `phone` / `address` = וויז / `email` / קישור רגיל), ו־`style` (`primary` = מלא, `secondary` = מתאר) |
| `certificates` | הכרטיסים "השכלה וניסיון" בעמוד אודות: שם, מוסד, שנה, ותמונה (לא חובה – לחיצה עליה מגדילה) |
| `contact` | טלפון, וואטסאפ (בפורמט `972501234567`), כתובת, רחוב ועיר (לגוגל), ערים באזור (`area_served`), פייסבוק |

**כללי זהב:**
- משנים רק את מה **שבין המירכאות** `"..."`.
- בין פריטים ברשימה חייב **פסיק** – ואחרי הפריט האחרון **אין** פסיק.
- שדה ריק `""` פשוט לא מוצג באתר.
- אם משהו נשבר (פסיק/מירכאה חסרים) – התצוגה המקומית תציג הודעת שגיאה במקום האתר.

## 📁 `pages/` – עמוד לכל לשונית
כל קובץ `.md` = עמוד אחד = לשונית אחת בתפריט.

| קובץ | עמוד |
|---|---|
| `index.md` | דף הבית (רק המשפט הקצר מתחת לשם) |
| `about.md` | אודות |
| `specialties.md` | התמחויות |
| `language-therapy.md` | טיפולי שפה |
| `language-assessment.md` | אבחוני שפה |
| `faq.md` | שאלות ותשובות |
| `contact.md` | צור קשר (פרטי הקשר נוספים אוטומטית מ־`content.json`) |

**מבנה כל קובץ** – הגדרות למעלה בין שני קווים `---`, והטקסט למטה:
```
---
nav: אודות                 ← השם בתפריט
title: אודות               ← הכותרת בראש העמוד
order: 2                   ← המקום בתפריט
description: ...           ← התיאור שגוגל מציג בתוצאות
image: assets/clinic.webp  ← תמונה (לא חובה)
image_alt: ...             ← תיאור התמונה (לגוגל ולעיוורים)
image_shape: house         ← צורה: house / blob / arch / circle
certificates: true         ← להציג את כרטיסי ההשכלה (רק באודות)
layout: faq                ← רק בשאלות (faq) ובצור קשר (contact)
---

כאן הטקסט. שורה ריקה = פסקה חדשה.
**מודגש**   - פריט ברשימה   [טקסט](https://קישור)
```
- **בשאלות ותשובות:** כל שאלה מתחילה ב־`## `, והתשובה בשורה שאחריה.
- **עמוד חדש:** יוצרים קובץ חדש כאן (שם באנגלית, למשל `prices.md`) – והוא נכנס לתפריט לבד.

## 🌐 אנגלית – `content.en.json` ו־`pages/en/`
- העברית בכתובת הראשית, האנגלית תחת `/en/` (למשל `.../linor-speech/en/about.html`).
- כפתור **EN / עב** בראש כל עמוד עובר לאותו עמוד בשפה השנייה.
- `content.en.json` – רק מה ששונה באנגלית (שם, תיאור, כפתורים, תעודות, כתובת לתצוגה). כל השאר (טלפון, תמונות, גוגל) נלקח מ־`content.json`.
- `pages/en/` – אותם קבצים כמו ב־`pages/`, באנגלית. **שם הקובץ חייב להיות זהה** לעברי – כך הכפתור יודע לאיזה עמוד לעבור.
- מוסיפים עמוד חדש? מוסיפים אותו גם ב־`pages/en/` (אחרת הכפתור יוביל לדף הבית באנגלית).
- כיווניות (ימין↔שמאל) מתחלפת אוטומטית, והכפתורים הצפים עוברים לצד ימין באנגלית.

## 📁 `assets/` – כל מה שעולה לאתר חוץ מהטקסט

| קובץ | מה הוא |
|---|---|
| `style.css` | **כל העיצוב.** בראש הקובץ – הצבעים (`--sage`, `--clay`...) והגופן. שינוי צבע במקום אחד משנה אותו בכל האתר |
| `site.js` | התנהגות: תפריט ההמבורגר בטלפון, הגדלת תמונות תעודות, ספירת לחיצות לגוגל אנליטיקס |
| `linor.webp`, `clinic.webp`, `games.webp` | התמונות באתר |
| `waze.webp`, `whatsapp.png` | אייקוני וויז ווואטסאפ – בכפתורים הצפים ובעמוד צור קשר |
| `favicon-32.png`, `favicon-96.png` | האייקון בלשונית הדפדפן (האישה המאוירת) |
| `apple-touch-icon.png` | האייקון כשמוסיפים את האתר למסך הבית בטלפון |
| `og-image.jpg` | התמונה כששולחים קישור בוואטסאפ. ⚠️ הטקסט בה **צרוב בתמונה** – שינוי שם/פרטים דורש ליצור אותה מחדש |

**תמונה חדשה:** עדיף WebP ברוחב ~800 פיקסלים, שומרים כאן, ומפנים אליה מהעמוד (`image: assets/...`).

## 🐍 `build.py` – המנוע
הסקריפט שבונה את האתר. **בדרך כלל לא נוגעים בו.** מה הוא עושה:
1. קורא את `content.json` ואת כל `pages/*.md`.
2. בונה מכל עמוד קובץ HTML – עם התפריט, הכפתורים הצפים (וואטסאפ ווויז) והתחתית.
3. מוסיף מידע לגוגל: מפת אתר (`sitemap.xml`), `robots.txt`, פרטי העסק ושאלות ותשובות.
4. מוסיף לכל קובץ "חותמת גרסה" (`?v=...`) – כדי שמבקרים חוזרים יקבלו את החדש מיד.
5. שם הכול בתיקייה `dist/`.

```
python build.py serve   ← תצוגה מקומית: http://localhost:8000 (מרעננים אחרי כל שמירה)
python build.py         ← רק בנייה
```

## גוגל – קידום וסטטיסטיקות
- **תיאור לכל עמוד** בתוצאות החיפוש – השורה `description:` בראש כל קובץ ב־`pages/`.
- **Google Analytics** – מזהה `G-...` בשדה `google.analytics_id`. נספרות כניסות, ולחיצות על וואטסאפ / טלפון / וויז / פייסבוק נשלחות כאירוע `contact_click`.
- **Google Search Console** – הקוד בשדה `google.site_verification`. אחרי האימות מגישים שם את `sitemap.xml`.
- **דומיין משלכם** – אם מחליפים כתובת, חובה לעדכן את `site.url` ב־`content.json` (אחרת תמונת הוואטסאפ וגוגל לא יעבדו נכון).

## תהליך עבודה רגיל
```
1. עורכים    content.json  או  pages/*.md
2. בודקים    python build.py serve   →  http://localhost:8000
3. שומרים    git add -A
             git commit -m "מה שיניתי"
4. מפרסמים   git push              ← אחרי כדקה האתר באוויר מתעדכן
```
- **לשמור גרסה עם תג:** `git tag -a site-style-5 -m "תיאור"` ואז `git push --follow-tags`
- **להסתכל על גרסה ישנה:** `git checkout site-style-3` – ולחזור להווה: `git checkout main`
- **כל התגים:** `git tag -n1`
