# אתר – לינור נזרי שר, קלינאית תקשורת

## עריכת תוכן

**טקסט העמודים** – בתיקייה `pages/`, קובץ לכל עמוד (כל קובץ = לשונית בתפריט):

| קובץ | לשונית |
|---|---|
| `index.md` | דף הבית |
| `about.md` | אודות |
| `specialties.md` | התמחויות |
| `language-therapy.md` | טיפולי שפה |
| `language-assessment.md` | אבחוני שפה |
| `faq.md` | שאלות ותשובות |
| `contact.md` | צור קשר |

בראש כל קובץ:
```
---
nav: שם הלשונית בתפריט
title: הכותרת בראש העמוד
order: מיקום בתפריט (1, 2, 3...)
---
```
בגוף הטקסט: שורה ריקה בין פסקאות, `- ` לרשימה, `**מודגש**`, `[קישור](https://...)`.
בשאלות ותשובות: כל שאלה מתחילה ב־`## `, והתשובה בשורה שאחריה.
עמוד חדש = קובץ `.md` חדש בתיקייה (שם הקובץ באנגלית).

**פרטים כלליים** – בקובץ `content.json`: שם, טלפון, וואטסאפ, מייל, כתובת, כפתורי דף הבית.
שדה ריק `""` לא מוצג. מספר וואטסאפ בפורמט `972501234567`.

**תמונה בדף הבית** – `assets/linor.webp`. צורה: `"photo_shape": "circle"` (עיגול) או `"square"` (ריבוע).

**תמונה בעמוד** – מוסיפים בראש קובץ העמוד:
```
image: assets/clinic.webp
image_alt: תיאור קצר של התמונה
```
העמוד יוצג עם הטקסט ליד התמונה (במסגרת קשת). כרגע: אודות ← `clinic.webp`, טיפולי שפה ← `games.webp`.
עדיף להקטין תמונות לפני העלאה (עד 1200 פיקסלים). המקוריים שמורים ב־`originals/`.

**תעודות** – ב־`content.json` תחת `certificates`. לכל תעודה: שם, מוסד, שנה, ותמונה/סריקה (למשל `assets/certificates/degree.jpg`) – לחיצה עליה מגדילה. מוצג בעמוד שבראשו `certificates: true` (כרגע אודות).

**צבעים** – בראש `assets/style.css` (לבן, ירוק מרווה, חימר).

## גוגל: קידום וסטטיסטיקות
- **תיאור לכל עמוד** (מה שמופיע בתוצאות החיפוש) – השורה `description:` בראש כל קובץ ב־`pages/`.
- **Google Analytics** – מזהה `G-...` בשדה `google.analytics_id` ב־`content.json`. נספרות כניסות, ולחיצות על וואטסאפ/טלפון/וייז/פייסבוק נשלחות כאירוע `contact_click`.
- **Google Search Console** – הקוד בשדה `google.site_verification`. מגישים שם את `sitemap.xml`.
- נבנים אוטומטית: `sitemap.xml`, `robots.txt`, ומידע מובנה לגוגל (פרטי העסק בדף הבית, שאלות ותשובות).
- כל קובץ עיצוב/תמונה מקבל חותמת גרסה (`?v=...`), כך שמבקרים חוזרים מקבלים את הגרסה החדשה מיד.

## הרצה מקומית
```
python build.py serve
```
ונכנסים ל־http://localhost:8000. אחרי שמירת שינוי מספיק לרענן את הדפדפן.

## העלאה לאוויר (GitHub Pages)
1. יוצרים ריפו בגיטהאב ודוחפים לענף `main`.
2. בריפו: **Settings → Pages → Source: GitHub Actions**.
3. כל push ל־`main` בונה ומעלה את האתר אוטומטית (`.github/workflows/deploy.yml`).
4. אחרי שיש כתובת סופית/דומיין – לעדכן את `site.url` ב־`content.json`.
